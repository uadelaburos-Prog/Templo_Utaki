## Flujo

1. Lee las secciones relevantes de `CLAUDE1.md` para entender las restricciones del GDD (mecánicas existentes, niveles, enemigos, restricciones de diseño).
2. Genera 3–5 ideas concretas y distintas. Para cada una:
   - **Qué es:** descripción en 1–2 oraciones
   - **Por qué encaja:** cómo se relaciona con la mecánica core del gancho o la progresión de niveles
   - **Riesgo / costo:** tiempo de implementación estimado y posibles problemas
   - **GDD fit:** ✅ consistente / ⚠️ extensión del GDD / ❌ contradice GDD (explicar)
3. Recomienda una idea como punto de partida, con justificación breve.
4. No implementes nada — este comando es solo para explorar opciones. La decisión final es de Bonio.
